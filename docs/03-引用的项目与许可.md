# 引用的项目与许可

## cccodroid — greyoak111/cccodroid

- 许可：Apache-2.0
- 用途：本应用的全部实时数据都来自它的本地网关（`127.0.0.1:8791` 的 `/api/state`、`/api/billing`、`/api/usage`、`/api/perm/answer`）；它的 `X-CC-Token` 机制决定了本应用的接入方式；构建链（aapt2 + javac + d8 + apksigner，不依赖 Gradle）也是照着它的做法。
- 代码没有直接拷贝；接口路径与字段按它的行为对齐。

## agent-hud-open — jazzenchen/agent-hud-open

- 许可：Apache-2.0
- 用途：视觉语言的来源——四态（干活 / 等待 / 询问 / 完成）、Bot 的形态与眼睛、额度圆环、灵动岛式的胶囊。本项目的 Bot 绘制、圆环、颜色与状态映射参考了它；`model_*.png` 模型图标取自它的素材目录。
- 商标：Claude、ChatGPT、DeepSeek、Codex 等名称与图标归各自所有者。

## 模型图标 — LobeHub

- 许可：MIT
- 用途：agent-hud-open 仓库内 `model_*.png` 的原始来源；本仓库沿用该许可说明。

## Android Open Source Project

- 许可：Apache-2.0
- 用途：平台 API（`WindowManager` 悬浮窗、`FramePath` 用到的 `Canvas`/`Path` 绘制、`SharedPreferences`）。

## 没有使用的

- Shizuku：本应用没有申请任何特权，悬浮窗与网络都在普通应用权限内。
